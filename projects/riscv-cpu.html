01 / ARCHITECTURE

Building the core.

I designed and implemented the CPU’s ALU, register file, control decoder, immediate generator, and memory subsystem in SystemVerilog.

The single-cycle architecture brings these components together to execute RV32I instructions. The project covers both the hardware implementation and the tooling needed to test it.

02 / VERIFICATION

Test at every level.

I built a layered verification suite to check individual modules and the integrated processor.

  • Per-module unit testsCheck the individual building blocks of the CPU.
  • Full-core instruction regressionA 24-check regression exercises the integrated core.
  • Randomized differential testingCompare results against a Python golden model. More than 10,000 randomized ALU instructions achieved a 100% pass rate.

03 / TOOLING

An assembler for the tests.

I wrote a two-pass Python assembler with label resolution to generate test programs. It eliminates hand-computed branch and jump offsets, making test programs easier to write and update.

04 / LINT & SYNTHESIS

From RTL to a netlist.

I checked the design with Verilator lint and synthesized it with Yosys. The synthesis run produced a clean 121-cell gate-level netlist with no synthesis errors.
